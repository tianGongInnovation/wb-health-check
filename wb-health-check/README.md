# 健康检查（wb-health-check）

WorkBuddy 自身 + 电脑系统的健康巡检技能：跑一次随附脚本，输出 GREEN/YELLOW/RED 三色状态、具体告警和处置建议，帮你在"还不安全"变成"已经出事"之前就收到提醒。

由 **天工创新坊** 开发维护，许可 **CC BY 4.0**（署名即可自由使用、修改、分发）。

## 有什么用处？

- 一条命令跑完巡检（约 2 秒），覆盖：WorkBuddy 进程数/内存占用、系统剩余内存/上线时间、CPU 负载、进程总数与无响应进程、句柄数、C 盘空间，可选显卡状态
- 三色状态 + 白话告警 + 处置建议：GREEN 不打扰，YELLOW/RED 一句话说清该干什么（保存工作 → 重启智能体或另开新会话）
- 面向普通人的普通电脑：轻（无常驻、无后台）、白（提醒全用白话中文）、够用（先防住最常见的翻车）

## 为什么要用？

智能体长时间高强度工作后可能静默退出（无崩溃转储、无系统报错，界面和后台悄悄消失），使用者往往误以为是电脑坏了而去重启整机。本技能把这些"出事前兆"变成明确的指标和阈值，及时提醒，避免白折腾。

## 如何用？

1. 本技能是为 WorkBuddy 等智能体（Agent）准备的：安装到智能体的技能目录后，直接说"跑下健康检查""WB 还活着吗"，智能体会调用随附的 `scripts/wb_health_check.ps1`
2. 也可手动运行：

   ```powershell
   powershell -ExecutionPolicy Bypass -File "<技能目录>/scripts/wb_health_check.ps1"
   ```

   加 `-Log` 参数可把每次结果追加到日志，便于长期趋势观察

## 有问题怎么办？

- 提示"技能目录里缺少 scripts/wb_health_check.ps1" → 重新安装本技能
- YELLOW/RED 告警出现 → 按提示处理即可；不处理也能继续用，但出问题别意外
- 阈值想按自己机器调整 → 脚本同目录放一个 `thresholds.json` 即可覆盖任意阈值，不必改脚本
- 问题反馈：本仓库 Issues（优先）或联系邮箱 gouzhongwu@vip.qq.com
